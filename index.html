Supplementary Materials

Title: Physics-Informed Neural Networks: A Didactic Derivation of the Complete Training Cycle

Journal: SIAM Review, Education Section

Contents

File Description
PINN_Didactic_Notebook.ipynb Interactive Jupyter Notebook (Python 3 / PyTorch). Part 1 reproduces every manual calculation from Sections 2–3. Part 2 executes the full training and validation pipeline and generates all publication figures.
pinn_trained_model.pt Trained model checkpoint containing the 22 optimized parameters (PyTorch state_dict format).
pinn_results.json Evaluation metrics and pointwise predictions. All values in Section 4 are read directly from this file.
pinn_loss_history.npz Epoch-by-epoch loss history (NumPy compressed archive). Used to generate the loss convergence figure.
figures/ Publication-quality figures in PDF format.
README.txt Requirements, installation instructions, and usage guide.

Requirements

  • Python ≥ 3.8
  • PyTorch ≥ 1.10
  • NumPy ≥ 1.20
  • Matplotlib ≥ 3.4

Reproducibility

A fixed random seed ensures identical results across platforms. The notebook can also be executed directly in Google Colab without any local installation.
